# German Declension Exercises

Fill-in-the-gap template sentences to practise articles, *ein/kein*/possessives and adjective endings in every case. This goes with the **German Declension Cheat Sheet**.

---

## How to use

- Each **[___]** is a gap for a noun phrase: **(article) + (adjective) + noun**.
- The sentence decides the case. Where the case isn't obvious, it's given in brackets after the sentence.
- The sample answers after **→** are only suggestions. Make your own combinations by changing the article type, the adjective and the noun's gender.
- When a sentence has several gaps, each answer gives the fills **in order**, separated by **/**.
- The subjects are singular so the verb stays the same. If you use a plural subject, change the verb too: *sieht → sehen*, *ist → sind*.

### Building blocks
- **Article types:**
    - none
    - der / das / die
    - ein / kein
    - mein, dein, sein, ihr, unser, …
    - dieser, jeder
- **Nouns:**
    - masculine: der Mann, Tisch, Hund, Freund
    - neuter: das Kind, Haus, Buch, Auto
    - feminine: die Frau, Lampe, Stadt, Katze
    - plural: die Leute, Freunde, Kinder
    - n-nouns: der Student, Nachbar, Junge, Kollege
- **Adjectives:** alt, neu, jung, klein, groß, nett, schön

**Example:** sentence 16 + *ein* + *nett* + *Nachbar* gives *Ich spreche mit ein**em** nett**en** Nachbar**n***.

### Two questions to ask every time
1. **Which case?** Look at the verb or the preposition.
2. **Does the article already show it?** If yes, the adjective takes *-e* or *-en*. If not, the adjective takes the strong ending.

# Part 1: One gap

## Nominativ

1. **[___]** wartet vor der Tür.
   → der alte Mann · ein netter Student · eine junge Frau · unser kleiner Hund
2. Das ist **[___]**.
   → der neue Tisch · ein kleines Kind · meine nette Nachbarin · *(plural: Das sind)* meine alten Freunde
3. Hier wohnt **[___]**.
   → der nette Nachbar · eine alte Frau · unser neuer Student
4. **[___]** gefällt mir sehr.
   → das neue Haus · die schöne Lampe · dieser große Tisch
5. Er wird **[___]**.
   → ein guter Student · ein netter Nachbar · ein großer Mann

## Akkusativ

6. Ich sehe **[___]**.
   → den alten Mann · einen netten Studenten *(n-noun)* · das kleine Kind · keine alten Leute
7. Wir suchen **[___]**.
   → einen großen Tisch · das neue Buch · unseren Nachbarn *(n-noun)* · kleine Hunde
8. Sie kauft **[___]**.
   → einen neuen Tisch · ein großes Haus · die schöne Lampe · neue Bücher
9. Es gibt hier **[___]**.
   → einen großen Hund · ein altes Haus · nette Leute
10. Das Geschenk ist für **[___]**. *(für + Akk)*
    → den kleinen Jungen *(n-noun)* · ein nettes Kind · meine Frau · unsere alten Freunde
11. Ohne **[___]** gehe ich nicht. *(ohne + Akk)*
    → meinen alten Hund · mein neues Buch · meine Freunde
12. Wir gehen durch **[___]**. *(durch + Akk)*
    → einen kleinen Park · die alte Stadt · das große Haus

## Dativ

13. Ich helfe **[___]**. *(helfen + Dat)*
    → dem alten Mann · einer netten Frau · meinem kleinen Kind · dem jungen Studenten *(n-noun)* · alten Leuten
14. Das Buch gehört **[___]**. *(gehören + Dat)*
    → dem kleinen Jungen *(n-noun)* · meiner alten Freundin · unserem Nachbarn *(n-noun)* · diesen netten Leuten
15. Ich gebe **[___]** einen Apfel. *(indirect object)*
    → dem kleinen Kind · einem netten Jungen *(n-noun)* · der alten Frau · meinen Freunden
16. Ich spreche mit **[___]**. *(mit + Dat)*
    → einem netten Nachbarn *(n-noun)* · der jungen Frau · meinem alten Freund · kleinen Kindern
17. Sie wohnt bei **[___]**. *(bei + Dat)*
    → einer netten Frau · ihrem neuen Freund · den alten Leuten
18. Er kommt gerade von **[___]**. *(von + Dat)*
    → dem netten Nachbarn *(n-noun; von dem → vom)* · einer alten Freundin · seinen Eltern

## Two-way prepositions (Akk or Dat)

19. Ich stelle die Tasche neben **[___]**. *(Wohin? → Akk)*
    → den großen Tisch · das alte Bett · die kleine Lampe
20. Die Tasche steht neben **[___]**. *(Wo? → Dat)*
    → dem großen Tisch · dem alten Bett · der kleinen Lampe
21. Die Katze springt auf **[___]**. *(Wohin? → Akk)*
    → den neuen Tisch · das große Sofa · die alte Kiste
22. Die Katze sitzt auf **[___]**. *(Wo? → Dat)*
    → dem neuen Tisch · dem großen Sofa · der alten Kiste

> **Tip:** Practise 19/20 and 21/22 as pairs. The noun phrase changes only because of *Wohin?* vs *Wo?*.

## Genitiv

23. Das ist das Auto **[___]**.
    → des alten Mannes · meines netten Nachbarn *(n-noun)* · der jungen Frau · meiner Eltern
24. Der Name **[___]** ist schwer.
    → des kleinen Kindes · des neuen Studenten *(n-noun)* · dieser schönen Stadt · eines alten Freundes
25. Wegen **[___]** bleiben wir zu Hause. *(wegen + Gen)*
    → des schlechten Wetters · der kalten Tage · eines kranken Kindes
26. Trotz **[___]** sind wir froh. *(trotz + Gen)*
    → des starken Regens · der langen Reise · aller Probleme

# Part 2: Two gaps

    → der kleine Junge / seinen großen Hund · die alte Frau / ihre kleine Katze

## Nom + Dat

32. **[___]** hilft **[___]**.
    → der junge Student / der alten Frau · eine nette Frau / dem kleinen Jungen · mein Nachbar / meinen Eltern
33. **[___]** gehört **[___]**.
    → das große Haus / dem alten Mann · der kleine Hund / einem netten Nachbarn · die neue Lampe / meiner Frau

    → der Lehrer / dem neuen Studenten · die junge Frau / ihrem alten Freund
36. **[___]** dankt **[___]**.
    → das kleine Kind / der netten Frau · der alte Mann / seinem Nachbarn

## Dat + Akk (fixed subject)

37. Ich gebe **[___]** **[___]**. *(Dat + Akk)*
    → dem kleinen Kind / einen roten Apfel · der alten Frau / meinen Platz · meinem Nachbarn / den neuen Schlüssel
38. Sie schenkt **[___]** **[___]**. *(Dat + Akk)*
    → ihrem jungen Bruder / ein neues Buch · ihren Freunden / eine schöne Lampe · dem netten Studenten / einen alten Tisch
39. Er zeigt **[___]** **[___]**. *(Dat + Akk)*
    → dem neuen Kollegen / das große Büro · seiner Frau / die alte Stadt
40. Wir erklären **[___]** **[___]**. *(Dat + Akk)*
    → dem kleinen Jungen / das neue Spiel · den neuen Studenten / die schwierige Regel

> **Word order:** When both objects are nouns, the Dativ comes before the Akkusativ. When the Akkusativ is a pronoun, it comes first: *Ich gebe **ihn** dem Kind.*

## Nom + preposition

41. **[___]** wohnt bei **[___]**. *(Nom + Dat)*
    → der junge Student / einer netten Familie · meine Freundin / ihren alten Eltern
42. **[___]** kauft ein Geschenk für **[___]**. *(Nom + Akk)*
    → die junge Frau / ihren netten Nachbarn · der kleine Junge / seine alte Oma
43. **[___]** spricht mit **[___]**. *(Nom + Dat)*
    → der neue Student / dem alten Lehrer · eine nette Frau / meinen Freunden

## Nom + Gen

44. **[___]** ist der Bruder **[___]**.
    → der junge Mann / der netten Frau · dieser kleine Junge / meines alten Freundes
45. **[___]** steht vor dem Haus **[___]**.
    → ein großes Auto / des neuen Nachbarn · der kleine Hund / meiner Eltern
46. Wegen **[___]** kommt **[___]** nicht. *(Gen + Nom)*
    → des schlechten Wetters / der alte Mann · einer langen Reise / meine Freundin

> Here the subject comes after the verb, because the sentence starts with *wegen*.

## Nom + two-way preposition

47. **[___]** legt das Buch auf **[___]**. *(Wohin? → Akk)*
    → der junge Student / den großen Tisch · die alte Frau / das kleine Regal
48. **[___]** liegt auf **[___]**. *(Wo? → Dat)*
    → das neue Buch / dem großen Tisch · der kleine Hund / dem alten Sofa
49. **[___]** geht in **[___]**. *(Wohin? → Akk)*
    → die junge Frau / die neue Bibliothek · der Student / den großen Park
50. **[___]** arbeitet in **[___]**. *(Wo? → Dat)*
    → mein netter Nachbar / einem großen Büro · die junge Frau / der neuen Bibliothek
