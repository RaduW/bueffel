## Prompt 1

Have a look at the file German Declination.md from the root directory.
Now I want to create a program, use a html page and some javascript (maybe some css as well).

The program should allow you to practice the tables from above.
It should allow to select one or more of the exercises above: definite article + noun | indefinite article or kein / mein ... +noun | adjective + noun | definite article adjective noun | ...

Then present a question by showing a case Nom, Accusative ... , a noun Mann, Frau ... and if needed a adjectie.
Below it should present multiple options that can be clicked so for example for the definite article should show der, den, die, dem ... for the adjective alt, altes, alten ... , for the noun Mann, Mannen , Mannes .... .
Then the use should be able to click any of the presented options.
For example der alte mann . When the correct choice si made it should turn green, when the incorrect option is pressed it should turn red. Then a count of how many exercises have been shown and how many have been done without mistake. Save this information in the local storage, so it is sort of persistent.
